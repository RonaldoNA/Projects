Para las guías de onda:
\begin{itemize}
    \item Una guía de onda pose un indice de refracción en el otro núcleo, rodeado por otro de menor indice $n_1 < n_2$
    \item Para una única guía de onda, los modos admitidos están dados por sus características físicas. 
    \item Un arreglo de guías de onda, el acoplamiento permitirá la transferencia entre los elementos del arreglo.
\end{itemize}
\begin{align}
    i \frac{dE_j(z)}{dz} = g_1 (E_{j-1} + E_{j+1}), \quad j = -\infty, \dots, \infty,
\end{align}

\begin{align}
     i \frac{d|\psi(z)\rangle}{dz} = \hat{H}|\psi(z)\rangle, \quad \hat{H} = g_1 \left( \hat{V}_\infty + \hat{V}_\infty^\dagger \right),
\end{align}

\begin{align}
      \hat{V}_\infty = \sum_{n=-\infty}^{\infty} |n\rangle \langle n+1|, 
\quad \hat{V}_\infty^\dagger = \sum_{n=-\infty}^{\infty} |n+1\rangle \langle n|, 
\end{align}

Algo importante de estos operadores es que cumplen con
\begin{align*}
    \left[\hat{V}_\infty, \hat{V}_\infty^\dagger\right] &= 0, \qquad \hat{V}_\infty \hat{V}_\infty^\dagger = \hat{I},
\end{align*}
Dada una condición inicial $\ket{\psi(0)} = \ket{n_0}$, la solución formal a la ecuación de Schrödinger es:
\[
\ket{\psi_{n_0}(z)} = \exp\left[-g_1 z \left(i\hat{V}_\infty^\dagger - \frac{1}{i\hat{V}_\infty^\dagger}\right)\right] \ket{n_0}.
\]
Donde podemos identificar la función generadora de las funciones Bessel$^1$ $^2$, para obtener
\[
\ket{\psi_{n_0}(z)} = \sum_{n=-\infty}^{\infty} J_n(-2g_1 z)i^n \hat{V}_\infty^{\dagger n} \ket{n_0}.
\] 
para este modelo podemos hacer una analogía con un modelo de bosones en una red óptica:
\[
\hat{V}_\infty = \sum_{n=-\infty}^{\infty} \hat{b}_n^\dagger  \hat{b}_{n+1}, \quad \hat{V}_\infty^\dagger = \sum_{n=-\infty}^{\infty} \hat{b}_{n+1}^\dagger \hat{b}_{n}  
\] 
\[
\ket{\psi_{n_0}(t)} = \sum_{n=-\infty}^{\infty} J_n(-2 J t)i^n \hat{V}_\infty^{\dagger n} \ket{n_0}.
\]  
Para diferentes estados iniciales tenemos diferentes representaciones para el operador $\hat{V}^{\dagger n}_\infty$: 
\[
\hat{V}^{\dagger n}_\infty |1_0\rangle = \hat{c}^\dagger_n |0\rangle
\] 
\[
\hat{V}^{\dagger n}_\infty |2_0\rangle = \frac{1}{\sqrt{2}} \sum_{k=0}^n \binom{n}{k} \hat{c}^\dagger_n \hat{c}^\dagger_{n-k} |0\rangle
\]  
Y dependiendo del estado inicial podemos encontrar una forma cerrada para la resolución de valores de expectación : 
\[ 
\langle \hat{n}_j \rangle = |\mathrm{J}_j ( -2Jt)|^2
\] 
\[ 
\mathrm{S}(q) = \sum_{l=0}^M |\mathrm{J}_l ( -2Jt)|^2 - \sum_{l, m=0}^M e^{\mathrm{iq}(l-m)} |\mathrm{J}_l ( -2Jt)|^2  |\mathrm{J}_m ( -2Jt)|^2
\]
